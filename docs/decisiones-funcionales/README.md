# Decisiones funcionales

Usar esta carpeta para requisitos, actores, permisos, reglas de negocio, flujos, validaciones, criterios de aceptación y cambios materiales de alcance funcional.

## Formato recomendado

Cada decisión debe indicar:

- fecha;
- estado: `PROPUESTA`, `CONFIRMADA`, `PENDIENTE`, `SUPERSEDED` o `POST-MVP`;
- necesidad/origen;
- actores afectados;
- comportamiento confirmado;
- validaciones y errores;
- criterios de aceptación;
- fuera de alcance;
- trazabilidad con issues/PR;
- decisiones anteriores sustituidas.

No inferir comportamiento no aprobado para completar huecos.
