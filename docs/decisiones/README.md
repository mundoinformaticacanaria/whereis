# Decisiones materiales

Usar esta carpeta para decisiones de arquitectura, gobernanza, seguridad, privacidad, persistencia, proveedores, infraestructura, costes o alcance técnico.

## Formato recomendado

Cada decisión debe indicar:

- fecha;
- estado: `PROPUESTA`, `CONFIRMADA`, `PENDIENTE`, `SUPERSEDED` o `POST-MVP` cuando aplique;
- contexto;
- decisión;
- alternativas consideradas;
- consecuencias/riesgos;
- issues/PR relacionadas;
- qué decisión sustituye, si corresponde.

No reescribir la historia para ocultar decisiones antiguas: marcar las superadas como `SUPERSEDED` y enlazar la vigente.
